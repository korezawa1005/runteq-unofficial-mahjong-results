# RUNTEQ非公式麻雀サークル：成績表

RUNTEQ非公式麻雀サークルの四人麻雀・半荘の順位と終了時点数を記録し、個人成績を表示するWebアプリです。

画面内の「らんてくん」画像は、[RUNTEQ公式ブログ](https://runteq.jp/blog/programing_school/teacher/1059/)掲載素材を使用しています。

## 起動

```sh
cd simple_app
python3 start_local.py
```

ブラウザで `http://127.0.0.1:8010` を開きます。データは `simple_app/data/results.sqlite3` に保存されます。

初回は「メンバー」画面で4〜12桁の管理者PINを設定します。一般メンバーは対局登録、年別・通算成績、指標別ランキング、全対局履歴を利用できます。ランキングは平均着順・トップ率・連対率・ラス回避率・飛び回避率で切り替えられます。管理者はメンバー管理、対局の編集・削除、共通アクセスPINの設定、JSONバックアップ・復元を行えます。

ランキングの規定対局数は、選択期間内で10半荘です。10半荘未満の成績も数値を確認できますが、順位は付けず参考記録として表示します。

順位は1〜4位の行で指定します。同点も記録でき、その場合は上の行のメンバーを上位として保存します。点数と順位が矛盾する場合や、4人の合計が100,000点にならない場合は保存できません。

共通アクセスPINを設定すると、URLを開いた一般メンバーにPIN入力を求めます。同じ端末では30日間入力を省略します。管理者PINでも入口を解除できます。

バックアップには全メンバーと全対局が含まれます。管理者PIN、共通PIN、ログイン情報は含まれません。

## テスト

変更内容に応じた確認範囲は [DEVELOPMENT.md](DEVELOPMENT.md) に記載しています。

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/test_stats.js
```

ブラウザテストを実行する場合だけ、`npm install` と `npx playwright install chrome` を実行します。
